Burn subtitles can use a TTF/OTF placed in this folder. Refresh repository fonts in the portal to select it.
IskoolaPota.ttf remains the default Sinhala font; modern version 6+ is required.
Noto Sans Sinhala, DejaVu Sans and DejaVu Serif can instead be selected without uploading a font.
The timed title uses Algerian.ttf when its name component is enabled.
Only upload/commit fonts if their license permits repository redistribution. No proprietary fonts are bundled.
